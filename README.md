## 🚀 Featured Projects  


### 🏥 wellora-ai-chatbot  
An intelligent AI-powered healthcare assistant designed to provide users with fast, accessible, and reliable medical guidance using advanced Natural Language Processing and Large Language Models. Wellora-ai-chatbot leverages modern AI techniques such as LLMs, NLP, Retrieval-Augmented Generation (RAG), GROQ inference, and GLM-V multimodal understanding to deliver context-aware health assistance. The system is designed to simulate a conversational medical assistant that can help users understand symptoms, suggest possible conditions, and provide general health information based on trusted knowledge sources.

### 🌿 MANGO-LEAF-DISEASE-DETECTION  
An AI-powered plant disease detection system designed to help farmers identify diseases in mango leaves using image classification techniques. The project aims to reduce crop loss by enabling early detection and providing actionable insights through machine learning. The system uses a trained deep learning model to analyze leaf images and classify diseases such as anthracnose, powdery mildew, bacterial canker, and dieback. It is designed as a scalable solution that can be integrated into mobile or web applications for real-time usage in agricultural fields.  

### 🤖 LINKEDIN-PROFILE-ENHANCER  
An AI-powered React-based web application designed to optimize LinkedIn profiles for ATS (Applicant Tracking System) compatibility and recruiter visibility. The platform uses Google Gemini API to intelligently generate and refine professional content in real time, helping users build stronger personal branding and improve job opportunities. This tool analyzes user inputs such as skills, experience, and job roles, and then generates high-quality, recruiter-friendly LinkedIn sections including headlines, summaries, and experience descriptions. The goal is to make profiles more impactful, keyword-optimized, and aligned with industry standards.
